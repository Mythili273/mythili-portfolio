## ✨ Features
- Multi-page navigation (Home, About, Skills, Projects, Certifications, Contact) with smooth page transitions
- Animated data-network background in the hero section
- Live-animated skill bars and a GPA count-up effect
- Interactive project cards with cursor-tracking hover glow
- Fully responsive — works on desktop and mobile
- Built with accessibility in mind (keyboard navigation, reduced-motion support)

## 🛠️ Tech Stack
- HTML5, CSS3 (custom properties, animations, responsive grid)
- Vanilla JavaScript (no frameworks — client-side routing, canvas animation, IntersectionObserver)
